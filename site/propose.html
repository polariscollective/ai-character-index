Propose a behaviour or a specification

The index tests behaviours against the specifications the labs publish. If there is a behaviour it should be testing, or a document it should be reading, this is where to say so. Proposals are read by a person. Running one costs money and is a decision we take, so nothing you send here appears in the reader by itself.

A behaviour A specification

A behaviour

A behaviour is one thing a specification might commit a model to, written so that a panel of judges can look for it. The two fields that matter are what the judges are asked and where the construct stops: without the second, every judge draws its own line and the verdicts are not about the same thing.

A specification

A document a lab has published about how its models should behave. Send the markdown, not a link alone: the index quotes specifications verbatim and pins every citation to the exact bytes it read, so it stores the text rather than fetching it later.

What happens to it

It is recorded, and we are told. Someone reads it, and if it is worth running we register it ourselves and put it to the panel, which is the step that costs money. If you gave an address we will use it; if you did not, watch the reader.

If you would rather not wait for us, the original tool runs from a bare clone and judges whatever you point it at: AndresCotton/ai-character-index.
